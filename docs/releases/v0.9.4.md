# v0.9.4

**Released:** 2026-10-24 · **Branch:** `main` · **Previous:** [v0.9.3](v0.9.3.md) (2026-10-24).

A patch so **a Cloud v1 stack's docs host gets its DNS record**, plus the cluster files since v0.9.3
(lake.live's live payments, `v1-eu` as production, `v1-dev` on its own Clerk app).

| Measured | Value |
|---|---|
| Resource kinds | 48 CRDs in `chart/crds` (unchanged) |
| Lake schema | unchanged: lake v0.5.0 (`9c7c2fc7`), through `0098_authentication_attempts` |
| Tests | see [Verification](#verification) |

## Changes

| PR | Change |
|---|---|
| [#928](https://github.com/oramasearch/orama-operator/pull/928) | With `cloudflare.manageDNS`, the docs site gets its DNS record like the dashboard, writer and readers: `<cr>-docs-dns`, proxied, pointing at the docs Ingress's address, removed when docs is disabled or has no host. `v1-eu`'s `docs.orama.ing` had a Ready Ingress and certificate but no record. Extra hosts still get none |
