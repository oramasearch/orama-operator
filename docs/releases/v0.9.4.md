| Tests | see [Verification](#verification) |

## Changes

- With `cloudflare.manageDNS`, the docs site gets its DNS record like the dashboard, writer and
  readers: `<cr>-docs-dns`, proxied, pointing at the docs Ingress's address, removed when docs is
  disabled or has no host. Before, a docs host could have a Ready Ingress and certificate but no record.
  Extra hosts still get none.

## Before it rolls

- Once this operator runs, an existing stack's docs record appears without any change to its
  `OramaCloudV1Set` or `OramaCloudV1`.
- Roll the managing cluster's operator first, then every leaf's `OramaOperator`.
