# v0.7.2

**Released:** 2026-10-20 · **Branch:** `main` · **Previous:** [v0.7.1](v0.7.1.md) (2026-10-20).

v0.7.2 is **a patch that moves the operator's copy of Lake's schema through `0090_billing_contacts`**
(#680, issue #656), so lake v0.3.1, which adds billing contacts
([lake#857](https://github.com/oramasearch/lake/issues/857)), can roll. Nothing else changes.

## What changes on the roll

Each Lake's `controldb-schema` Job runs again and applies `0090_billing_contacts`: the
`billing_contacts` table and `billing_contacts_guard`, additive. The restore rehearsal also counts
`billing_contacts_guard`. Lake images before v0.3.1 ignore the table. See
[`docs/lake/schema.md`](../lake/schema.md).

## What it does not include

Everything under [v0.7.1](v0.7.1.md)'s *does not include*.

## Known issues

Unchanged from [v0.7.1](v0.7.1.md#known-issues), security first. Also: the operator was OOMKilled
once at start-up on the managing cluster after the v0.7.1 upgrade (#677).
