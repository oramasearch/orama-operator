# v0.11.9

**Released:** 2026-10-31 · **Branch:** `main` · **Previous:** [v0.11.8](v0.11.8.md) (2026-10-31).

A patch release: **the hub Prometheus writes its configuration**, so it federates every cluster and evaluates the hub's alert
rules. After v0.11.7 both hubs and all three agents were Ready, but the hub Prometheus had no scrape targets: prometheus-operator
v0.94 writes no configuration for a Prometheus that sets none of the monitor selectors, so `additionalScrapeConfigs` and the rule
selector were ignored (`Reconciled=True ConfigurationUnmanaged`), and every agent reported `metricsConnected=false`.

**v0.11.8 was released but never rolled.** This release carries it too: the clusters go from v0.11.7 straight to v0.11.9, with
both fixes.

## What it includes

| PR | Change |
|---|---|
| [#1102](https://github.com/oramasearch/orama-operator/pull/1102) | The hub Prometheus sets a `scrapeConfigSelector` (and its namespace selector) for the hub's own ScrapeConfigs, of which there are none. It is there so prometheus-operator writes the configuration: the federation jobs and the hub's rules then load. `TestHubPrometheusIsPinnedAndScoped` fails without it |
| [#1103](https://github.com/oramasearch/orama-operator/pull/1103), from v0.11.8 | People can sign in to the Pixie hubs: the organisation's domain, and `spec.users` ([v0.11.8](v0.11.8.md)) |

## What it does not include

- Any change to the platform charts, Lake or Cloud v1.
- Live traces through a PxL script are still unproven ([observability.md](../infrastructure/observability.md)).

## Upgrading

- From v0.11.7, follow [v0.11.8's upgrade notes](v0.11.8.md#upgrading): its two optional CRD fields are widened by the CRD
  rollout ([crd-rollout.md](../operations/crd-rollout.md)), and each hub's file is applied after the roll to add its `users`.
- **What rolls on each cluster with the operator:** the operator, and the zetta-tunnel mesh pods, which carry a container from
  the operator image. No Lake or Cloud v1 workload changes. On the hubs, the hub Prometheus reloads its configuration.

## Known issues
