# v0.11.10

**Released:** 2026-10-31 · **Branch:** `main` · **Previous:** [v0.11.9](v0.11.9.md) (2026-10-31).

A patch release: **the Pixie UI and the hub's API server load the PxL script bundle.** Once people could sign in (v0.11.9), the UI
showed *"Failed to Load Script Bundles (Network Error (SCRIPT_BUNDLES_OVERRIDDEN))"*:
- **The UI's fetch was cross-origin.** It runs on `work.<domain>`, but it was given `https://<domain>/pxl_scripts/bundle.json`,
  another origin that sends no CORS headers, so the browser refused it.
- **The API server couldn't resolve the address.** It was given the same URL, which nothing in the cluster resolves.

## What it includes

- The UI gets `SCRIPT_BUNDLE_URLS=["/pxl_scripts/bundle.json"]`, a path on its own origin that the proxy already serves.
  The API server gets its own `SCRIPT_BUNDLE_URLS`, the bundle server's Service
  (`http://pixie-scripts.plc.svc:8080/pixie-scripts/bundle.json`). A render test pins both. No Pixie image changes.

## What it does not include

- Any change to the platform charts, Lake or Cloud v1.
- A fix for the hub Prometheus not reaching production leaves. Until then `ObservabilityClusterUnreachable` can fire for
  healthy production leaves.

## Upgrading

- No CRD changes.
- **What rolls on each cluster:** the operator and the zetta-tunnel mesh pods. On the hubs, the proxy and the API server roll
  with their new configuration. No Lake or Cloud v1 workload changes.
- **A browser that set `px-custom-script-bundle-paths`** to work around the error can remove it:
  `localStorage.removeItem('px-custom-script-bundle-paths')`.

## Known issues

- The hub cannot federate production leaves, so `ObservabilityClusterUnreachable` fires for them.
- kuberesolver 401 log noise on the hub's servers.
- Otherwise unchanged from [v0.11.9](v0.11.9.md#known-issues).
