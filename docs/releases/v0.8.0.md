# v0.8.0

**Released:** 2026-10-22 · **Branch:** `main` · **Previous:** [v0.7.3](v0.7.3.md) (2026-10-20).

v0.8.0 is **the security release from the multi-tenant security audit** (lake#873) **and the
pre-launch security review** (orama-bridge#223, tracker #786), with the features reviewed alongside
it. It vendors **lake v0.4.0's schema** (`0091` to `0093`), so lake v0.4.0 can roll after it. 78 pull
requests since v0.7.3 (89 non-merge commits).

> **Read [Before it rolls](#before-it-rolls).** Several changes need a Secret, an image, a decision or
> an applied file first, and several restart workloads on every cluster, production included.

| Measured | Value |
|---|---|
| Resource kinds | 48 CRDs in `chart/crds`, four new: `BackupSchedule`, `Backup`, `EdgeHostPolicy`, `CloudflareHostPolicy` |
| Lake schema | lake tag v0.4.0 (`9115632e`), through `0093_root_recovery_participants` (#847) |
| Tests | see [Verification](#verification) |
